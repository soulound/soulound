# 大手アパレル企業 ワークフロー構造

## 全体シーズンスケジュール

アパレル企業の業務はシーズン単位で回る。主要シーズンは **SS（春夏）** と **AW（秋冬）** の年2回。各シーズンの業務は約1年〜1.5年前から始まる。

```
───────────────────────────────────────────────────────────
 時期          SS（春夏）商品の場合        担当
───────────────────────────────────────────────────────────
 1.5年前       トレンドリサーチ・MD計画    MD / デザイナー
 1年前         デザイン企画・素材選定      デザイナー / パタンナー
 10ヶ月前      サンプル作成・展示会準備    生産管理 / デザイナー
 8ヶ月前       展示会・受注会             営業 / MD
 6ヶ月前       本生産発注・量産           生産管理 / 品質管理
 4ヶ月前       広報撮影・カタログ制作      広報 / クリエイティブ
 2ヶ月前       納品・検品                生産管理 / 物流
 店頭発売      販売開始                  営業 / 店舗 / EC
 シーズン中     追加発注・在庫調整         MD / 生産管理
 シーズン末     セール・在庫処分           営業 / MD
───────────────────────────────────────────────────────────
```

## 1. 商品企画・デザイン管理

### 関係者と役割

| 役職 | 責任範囲 | 判断権限 |
|------|---------|---------|
| **クリエイティブディレクター（CD）** | ブランド全体の世界観・方向性 | シーズンテーマの最終決定、デザイン却下権 |
| **デザイナー** | 個別アイテムのデザイン作成 | 色・柄・シルエットの提案（CDの承認が必要） |
| **パタンナー** | パターン（型紙）作成・仕様書作成 | サイズ・縫製仕様の技術判断 |
| **MD（マーチャンダイザー）** | 商品構成・価格・数量計画 | 商品化の可否判断、価格決定権 |
| **テキスタイルデザイナー** | 生地・素材の開発・選定 | 素材提案（CDとMDの承認が必要） |

### ワークフロー

```
CD: シーズンテーマ・コンセプト決定
 │
 ├──→ デザイナー: テーマに基づきデザイン画作成
 │     │  期限: テーマ決定後 2〜4週間
 │     │
 │     └──→ CD + MD: デザインレビュー会議
 │           │  判断: 商品化する／修正／却下
 │           │
 │           ├──→ [商品化決定] パタンナー: パターン作成・仕様書起票
 │           │     期限: デザイン承認後 2〜3週間
 │           │
 │           └──→ テキスタイルデザイナー: 素材手配・開発
 │                 期限: デザイン承認後 1〜2週間で素材確定
 │
 └──→ MD: 商品構成表（品番・価格・数量・投入時期）を策定
       期限: シーズン開始の10ヶ月前
       承認: 事業部長 or ブランド長
```

### デザイン管理で発生するデータ

- デザイン画（Adobe Illustrator / 手描きスキャン）
- 仕様書（品番・サイズスペック・素材指定・副資材・縫製指示）
- 素材スワッチ（反物見本）
- カラーパレット（Pantone指定）
- トワル・サンプル写真

## 2. 発注管理（生産管理）

### 関係者と役割

| 役職 | 責任範囲 | 判断権限 |
|------|---------|---------|
| **生産管理担当** | 工場選定・発注・納期管理 | 工場への発注実行（MD承認後） |
| **MD** | 発注数量・コスト管理 | 発注数量の最終決定、コスト上限の設定 |
| **品質管理（QC）** | 品質基準の設定・検品 | 出荷可否の判断 |
| **事業部長** | 予算管理 | 高額発注の承認（閾値以上） |
| **OEM/ODMパートナー** | 委託生産先 | 製造工程の実行判断 |

### ワークフロー

```
MD: 発注数量・上代（販売価格）・下代（仕入原価）を確定
 │  期限: 展示会 / 受注会の2週間後
 │  判断: 受注実績 or 見込み販売数に基づく
 │
 └──→ 生産管理: 工場に発注書（PO）発行
       │  期限: MD確定後 1週間以内
       │  判断: 工場キャパ・リードタイム・コストで工場選定
       │
       ├──→ 工場: 先上げサンプル（PP Sample）提出
       │     期限: 発注後 3〜4週間
       │     │
       │     └──→ QC + デザイナー: サンプル検査
       │           判断: 承認 / 修正指示 / 却下
       │           期限: サンプル到着後 1週間以内
       │
       ├──→ 工場: 量産開始
       │     期限: PPサンプル承認後〜納品日から逆算
       │
       ├──→ QC: 中間検品（インライン検品）
       │     工場現地で生産中の品質チェック
       │
       └──→ QC: 最終検品（出荷前検品）
             判断: 出荷許可 / 再検品 / 返品
             期限: 出荷予定日の1週間前
```

### 発注管理の主要帳票

| 帳票 | 作成者 | 承認者 | 用途 |
|------|-------|-------|------|
| 商品構成表 | MD | 事業部長 | シーズン全体の品番・数量・予算 |
| 発注書（PO） | 生産管理 | MD | 工場への正式発注 |
| 仕様書 | パタンナー | デザイナー + 生産管理 | 製造指示の詳細 |
| 検品報告書 | QC | 生産管理 | 品質合否記録 |
| 納品書 | 工場 | 生産管理 | 入庫確認 |

### 発注数量の決定ロジック

```
[展示会型ブランドの場合]
  受注会での小売店からの受注数 × 安全係数(1.05〜1.1) = 発注数量
  承認: MD → 事業部長（金額閾値超過時）

[SPA型（自社小売）の場合]
  前年同型商品の販売実績 × トレンド補正 × 店舗数補正 = 初回発注数量
  追加発注: 販売動向を見て週次〜隔週で判断（MD権限）
```

## 3. 広報管理（PR・クリエイティブ制作）

### 関係者と役割

| 役職 | 責任範囲 | 判断権限 |
|------|---------|---------|
| **PR / 広報マネージャー** | 広報戦略・メディア対応・予算管理 | 掲載媒体の選定、広報予算配分 |
| **プレス担当** | リース管理・メディアリレーション | 貸出可否の判断、撮影立会い |
| **クリエイティブディレクター** | ビジュアルの方向性 | 撮影カット・ビジュアル表現の最終承認 |
| **フォトグラファー（外部）** | 撮影実行 | 撮影時の技術的判断 |
| **スタイリスト（外部）** | コーディネート提案 | CDの方向性内でのスタイリング判断 |
| **デジタルマーケティング担当** | SNS・EC用素材管理 | SNS投稿内容の実行判断（マネージャー承認後） |
| **映像ディレクター（外部）** | 動画制作の演出 | 演出表現の提案（CD承認が必要） |

### 広報画像制作ワークフロー

```
PR マネージャー: シーズン広報計画を策定
 │  期限: シーズン開始の6ヶ月前
 │  判断: 予算配分、重点商品の選定
 │  承認: ブランド長 or マーケティング部長
 │
 ├──→ CD: ルックブック / カタログのビジュアルコンセプト決定
 │     期限: 広報計画承認後 2週間
 │
 ├──→ プレス担当: 撮影スケジュール手配
 │     │  ・モデルブッキング（モデルエージェンシー経由）
 │     │  ・スタジオ / ロケ地手配
 │     │  ・フォトグラファー / スタイリスト / HMU手配
 │     │  期限: 撮影日の4〜6週間前
 │     │
 │     └──→ 撮影実施
 │           │  立会い: CD + プレス担当 + デザイナー（必要時）
 │           │
 │           └──→ レタッチ・セレクト
 │                 │  フォトグラファー → CD: カットセレクト提出
 │                 │  CD: 使用カットの最終選定
 │                 │  レタッチャー: 色補正・加工
 │                 │  期限: 撮影後 2〜3週間
 │                 │
 │                 └──→ 各媒体への展開
 │                       ・ルックブック / カタログ: DTPデザイナー
 │                       ・EC掲載用: EC担当がリサイズ・加工
 │                       ・SNS用: デジタルマーケ担当が加工・投稿
 │                       ・プレスリリース添付: プレス担当
 │
 └──→ プレス担当: メディアリース管理
       ・雑誌 / WEB媒体からのサンプル貸出依頼対応
       ・貸出台帳管理（品番・貸出先・返却期限）
       ・撮影立会い（ブランドイメージ管理）
       判断: 掲載媒体の適合性、貸出可否
```

### 映像制作ワークフロー

```
PR マネージャー + CD: 映像企画・コンセプト決定
 │  期限: 公開予定日の3〜4ヶ月前
 │
 └──→ 映像ディレクター: 企画書・絵コンテ提出
       │  期限: 企画決定後 2週間
       │  承認: CD + PR マネージャー
       │
       ├──→ プリプロダクション（準備）
       │     ・キャスティング・ロケハン・衣装準備
       │     期限: 撮影日の2〜3週間前
       │
       ├──→ 撮影
       │     立会い: CD + プレス担当
       │
       └──→ ポストプロダクション
             │  ・編集 → ディレクターズカット提出
             │  ・CD確認 → 修正指示（通常2〜3回）
             │  ・音楽・SE・カラーグレーディング
             │  ・最終承認: CD + PR マネージャー + 法務（権利確認）
             │  期限: 撮影後 4〜6週間
             │
             └──→ 納品・公開
                   ・YouTube / SNS / 店頭サイネージ等へ展開
```

## 4. 権利管理（法務・知的財産）

### 関係者と役割

| 役職 | 責任範囲 | 判断権限 |
|------|---------|---------|
| **法務部 / 知財担当** | 商標・意匠・著作権の出願・維持管理 | 権利侵害の判断、法的措置の起案 |
| **ライセンス担当** | ライセンス契約の締結・管理 | ロイヤリティ条件の交渉（法務部長承認） |
| **法務部長** | 法的リスクの最終判断 | 訴訟・契約の最終承認 |
| **外部弁理士** | 商標出願・異議申立て対応 | 出願戦略の提案 |
| **外部弁護士** | 契約書レビュー・訴訟対応 | 法的アドバイス |

### 商標・ブランド権利管理

```
新ブランド / 新ライン立ち上げ時:
 │
 ├──→ 知財担当: 商標調査（先行商標の有無確認）
 │     │  期限: ブランド名決定前（必須）
 │     │  使用ツール: J-PlatPat（日本）、WIPO Global Brand Database（海外）
 │     │
 │     └──→ 外部弁理士: 商標出願
 │           ・国内: 特許庁へ出願（区分: 第25類 被服、第18類 鞄 等）
 │           ・海外: マドリッドプロトコルで一括出願 or 各国個別出願
 │           ・期間: 出願〜登録まで 約8〜12ヶ月（日本）
 │           承認: 法務部長
 │
 ├──→ 知財担当: 権利維持管理
 │     ・更新期限管理（10年ごと）
 │     ・不使用取消審判への対応
 │     ・類似商標の監視（ウォッチングサービス）
 │
 └──→ 知財担当: 権利侵害対応
       ・模倣品発見時: 警告書送付 → 法的措置検討
       ・EC プラットフォーム上の模倣品: 削除申請
       判断: 法務部長（訴訟判断は経営層承認）
```

### ライセンス管理

```
[ライセンスイン（他社の権利を借りる場合）]

企画部門: コラボ / ライセンス商品の企画起案
 │  承認: MD + 事業部長
 │
 └──→ ライセンス担当: 契約交渉
       │  ・ロイヤリティ率（通常 売上の5〜15%）
       │  ・最低保証金（ミニマムギャランティ）
       │  ・契約期間・対象地域・対象商品カテゴリ
       │  ・品質管理基準（ライセンサー承認プロセス）
       │  承認: 法務部長 → 経営層（金額規模による）
       │
       └──→ 生産開始前: ライセンサーによるデザイン承認
             ・デザイン画提出 → 承認 / 修正指示
             ・サンプル提出 → 承認 / 修正指示
             ・通常2〜3回の承認サイクルが必要
             期限: ライセンサーの承認フロー次第（2〜8週間）

[ライセンスアウト（自社の権利を貸す場合）]

ライセンス担当: ライセンシー候補の審査
 │  判断: ブランドイメージとの整合性
 │  承認: CD + 法務部長
 │
 └──→ 契約締結後: 品質管理
       ・ライセンシーからのデザイン承認依頼への対応
       ・定期的な品質チェック・店頭調査
       ・ロイヤリティ報告書の監査
```

### 広報素材の権利管理

```
撮影物の権利処理:
 │
 ├──→ モデル: 肖像権使用許諾書（モデルリリース）
 │     ・使用範囲: 媒体・期間・地域を明記
 │     ・更新: 契約期間超過時は再契約 or 素材使用停止
 │     管理: プレス担当
 │     承認: 法務部
 │
 ├──→ フォトグラファー: 著作権の帰属確認
 │     ・買取 or ライセンス（使用範囲の明記）
 │     ・二次利用の可否
 │     管理: プレス担当 + 法務部
 │
 ├──→ 音楽: 楽曲使用許諾
 │     ・既存楽曲: JASRAC等の許諾手続き
 │     ・オリジナル楽曲: 作曲家との権利帰属契約
 │     管理: PR マネージャー + 法務部
 │
 └──→ ロケ地: 施設使用許可
       ・撮影許可書の取得
       管理: プレス担当
```

## 5. 部門横断の意思決定構造

### 承認レベル一覧

```
レベル1（担当者判断）:
  ・日常的な業務遂行（発注書の事務処理、SNS投稿の実行等）
  ・金額: 〜50万円程度の支出

レベル2（マネージャー / MD判断）:
  ・商品化の可否、発注数量の確定
  ・広報施策の実行判断
  ・金額: 50万〜500万円程度

レベル3（部長 / ブランド長判断）:
  ・シーズン予算の承認
  ・新規取引先の承認
  ・重要な広報施策（大型タイアップ等）
  ・金額: 500万〜5,000万円程度

レベル4（経営層判断）:
  ・新ブランド立ち上げ
  ・大型ライセンス契約
  ・訴訟判断
  ・金額: 5,000万円以上
```

### シーズン会議体系

| 会議名 | 頻度 | 参加者 | 決定事項 |
|--------|------|--------|---------|
| トレンド会議 | シーズン初期に1回 | CD + デザイナー + MD | シーズンテーマ・方向性 |
| デザインレビュー | 週1回（企画期） | CD + デザイナー + MD + パタンナー | デザイン承認・修正指示 |
| サンプル検討会 | 随時 | CD + デザイナー + MD + 生産管理 | サンプル承認・量産可否 |
| 生産進捗会議 | 週1回（生産期） | 生産管理 + MD + QC | 納期確認・問題対応 |
| 広報企画会議 | 月1回 | PR + CD + MD + EC担当 | 広報施策・撮影計画 |
| 在庫会議 | 週1回（販売期） | MD + 営業 + EC担当 | 追加発注・値下げ・在庫移動 |
| 経営会議 | 月1回 | 経営層 + 各部門長 | 予算・戦略・重要案件承認 |

## 7. 管理システム（一般的に使用されるツール）

| 業務領域 | 一般的なシステム | 管理対象 |
|---------|----------------|---------|
| 商品企画 | PLM（Product Lifecycle Management） | デザインデータ・仕様書・承認フロー |
| 発注・生産管理 | ERP（SAP, Oracle等）/ 業界特化型 | 発注書・在庫・原価・納期 |
| 広報素材管理 | DAM（Digital Asset Management） | 画像・動画・使用権限・メタデータ |
| 権利管理 | 知財管理システム / 契約管理DB | 商標台帳・契約期限・ロイヤリティ |
| プロジェクト管理 | 各種PM ツール | タスク・スケジュール・担当者 |
